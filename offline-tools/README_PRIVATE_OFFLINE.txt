PRISON COST ESTIMATOR: PRIVATE DATA ADDED ON YOUR OWN COMPUTER
===============================================================

1. Open the successful GitHub Actions run for:
   Build offline app (private data added locally)
2. Download the Prison_Cost_Estimator_PRIVATE_READY artifact and extract its ZIP.
3. Open Prison_Cost_Estimator_LOCAL_PACKAGER.html in Microsoft Edge or Chrome.
4. Choose Prison_Cost_Estimator_BLANK_TEMPLATE.html for the template.
5. Choose your local private original-cost-rates.json for the rates.
6. Enter and confirm a new, strong passphrase (at least 12 characters).
7. Press Encrypt and create offline HTML.
8. Save Prison_Cost_Estimator_OFFLINE_PRIVATE.html and open it locally.
9. Unlock it with your passphrase and verify the costs and houseblock images.
10. Share it only through an approved Teams location and share the passphrase
    separately with authorised colleagues.

No real cost data or password needs to go into GitHub, GitHub Actions Secrets,
or ChatGPT. The blank GitHub workflow cannot access the real JSON.
The local browser packager reads the JSON and encrypts it on your own computer.
It clears file selections and password fields after use. It does not erase
the original source JSON on your computer; dispose of that file according to
your company's information security rules if required.

The finished HTML contains encrypted cost data. Anyone with the file and
passphrase can decrypt the rates. Shared copies cannot be remotely revoked.
Remember to validate commercial calculations before using them for decisions.

The original React components, CSS, fonts, images and calculation logic are
compiled into the blank HTML. This is not a redesigned interface.
