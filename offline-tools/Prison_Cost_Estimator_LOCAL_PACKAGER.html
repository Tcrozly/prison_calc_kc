Prison Cost Estimator - private data packager

Add your real cost rates to the original offline application, without uploading them to GitHub.

How this works

GitHub produces a blank, self-contained React application. This packager reads your JSON file on this computer, encrypts it with a passphrase you choose, and inserts the encrypted rates into the blank application.

Local-only processing: This page uses no external scripts, services or network requests. Your JSON and passphrase are not uploaded to GitHub or to this chat. Keep the finished HTML file and passphrase secure.

Open both this packager and the blank template from the ZIP you downloaded from GitHub Actions. No Node.js, software installation or hosting is needed.

Create your finished application

Select the two files and enter a passphrase to begin.

Finished file: Download the encrypted standalone HTML

For privacy, this tool clears its selected JSON file and passphrase fields after packaging. It does not delete your original JSON file from your computer; you control whether to retain or securely dispose of that original according to company policy. Closing the page releases its working data, although browser memory cannot be guaranteed to be securely erased.

Using and sharing the HTML

Double-click the finished Prison_Cost_Estimator_OFFLINE_PRIVATE.html, open it in Edge or Chrome and enter the passphrase you created. Check the calculations and original site images, then share the file through an approved Teams location. Share the passphrase separately with authorised colleagues.

Access limitation: anyone with the HTML file and its passphrase can decrypt the commercial rates. This is file encryption, not centrally managed access control. You cannot revoke copies already downloaded.
